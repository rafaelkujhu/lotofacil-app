📐 Tipo de Fechamento
ℹ️ Como funciona o Fechamento PRO
• O Fechamento trabalha com uma base fixa de dezenas.

• Quando a estratégia é Aleatória, a base é escolhida sem filtros estatísticos.

• Quando a estratégia é PRO, a base é formada apenas por dezenas vindas de jogos com bom score estatístico.

• No modo Automático, o sistema combina: score estatístico + simulação + equilíbrio matemático para selecionar a melhor base possível.

• O perfil (Conservador / PRO / Ousado) define o nível de risco aceito na seleção da base.

⚠️ O Fechamento não garante prêmio. Ele reduz jogos matematicamente fracos e melhora a qualidade das combinações.
